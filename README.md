# VR Ring Toss Tutorial

UnityとMeta Questを使った、VR輪投げ教材の原案・プロトタイプ・検証環境の制作プロジェクトです。
本リポジトリには、教材原案、Unityプロトタイプ、原案の全5章に対応する検証用プロジェクトを収録しています。

## 制作の目的

VR開発の初学者が、小さな仕組みを一つずつ作り、最後に遊べる輪投げへつなげることを目指しています。
掴む・投げるという体験を通じて、XRの入力、物理挙動、当たり判定、C#によるゲーム処理を学ぶ構成です。

## 担当範囲とAIの活用

**本リポジトリ作者**は、教材の目的・範囲・優先順位の決定、AIへの実装・検証依頼、教材原案・試作・検証環境の整備を担当しました。初期プロトタイプではQuest 2で実機確認し、結果をフィードバックしています。

コードや検証ツールの作成にはCodexなどのAI支援を活用しています。作者自身の企画・判断・実機確認と、AIによる実装・検証を組み合わせて制作しました。

## 原案・試作で取り組んだこと

- **VRでの掴み・投擲**：XR Interaction ToolkitとOpenXRを使い、近くの輪をGripで掴み、手を離して投げる操作を実装。
- **輪の穴を保つ物理形状**：16個のCapsule Colliderを組み合わせ、輪が棒を通る形状を構成。
- **得点判定・表示**：輪の位置・傾き・速度・条件の継続時間を組み合わせ、同じ投球での重複加点を防止。棒に触れただけでは得点にせず、輪が収まった状態を判定します。手で置いて離した場合も条件を満たせば得点します。[得点判定コード](Docs/CourseValidation/Sources/RingScore.cs)・[表示コード](Docs/CourseValidation/Sources/RingScoreDisplay.cs)を参照してください。
- **確かめながら学ぶ手順**：重力による落下、投擲倍率の比較、棒の真上からの落下試験、成功・失敗それぞれの得点確認を教材に組み込みました。
- **教材と検証の対応**：章ごとの保存シーン、教材掲載コードとの一致検査、物理・得点・復帰処理のPlayテストを用意。
- **再投球・交代**：右Aでの再投球、右Bでの得点リセットと交代を実装。保持中や解放直後の移動を防ぐ処理も追加。

原案の全5章は「掴む → 投げる → 的を作る → 得点を判定する → 表示と再投球を加える」の順で進みます。

## プロジェクトを開く

リポジトリには、用途の異なる2つのUnityプロジェクトがあります。

### 原案の全5章・検証用プロジェクトを見る

1. リポジトリを取得し、Unity Hubに **`CourseValidation/VRRT`** を追加します。
2. Unity **6000.3.9f1**で開き、パッケージの解決とインポートを待ちます。
3. `Assets/Scenes/05_RingToss.unity`を開きます。掴み・投擲・的・得点表示・再投球を含む第5章のシーンです。

各章の保存シーンも同じ`Assets/Scenes`内にあります。実機で試す場合はAndroid Build Support（SDK・NDK・OpenJDKを含む）と開発用に接続したQuestを用意し、Androidへ切り替えて対象シーンをBuild And Runします。

Questコントローラーでの想定操作は以下のとおりです。

- 輪に近づけて左右いずれかの**Gripを押す**：掴む
- **Gripを離す**：投げる
- **右A**：輪を前方へ戻して次の投球へ進む
- **右B**：得点を0にして輪を戻し、次の人へ交代する

以上はリポジトリ内の第5章の想定操作です。この検証用プロジェクトそのものの投げやすさ、A/Bの実ボタン入力、文字の見やすさは、記録上未確認です。

### 初期プロトタイプを見る

リポジトリ直下をUnity Hubに追加し、`Assets/RingTossTutorial/Scenes/RingToss_v0_1.unity`を開きます。
こちらは初期配置・掴み・投擲・右Aによる再投球までの試作版で、的・得点・UIは含みません。全5章の検証用プロジェクトとは別のプロジェクトです。
